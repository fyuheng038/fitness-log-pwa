## Exercise photographs and catalogue metadata

48 photographs (24 exercises), English names and muscle/equipment metadata originate from yuhonas/free-exercise-db, commit f00c92c7dcf1216a928a52c3706c7ce8e2f71ed5. Its README explicitly permits local use of the JSON data and images. The repository declares the Unlicense/public-domain dedication, reproduced at public/ExerciseDB-LICENSE.txt. Chinese names and concise instructions are authored for this project; examples show two still poses, not continuous video.

Source: https://github.com/yuhonas/free-exercise-db

The catalogue records each exercise's upstream source. scripts/media-manifest.json lists the pinned image URLs. No copyrighted Gym visual media from openGym is used.
